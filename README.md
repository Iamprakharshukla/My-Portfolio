# Prakhar Shukla - Portfolio

Welcome to the source code for my personal portfolio! This repository contains my premium, highly-interactive developer portfolio built to showcase my projects, experience, and technical skills.

## 🚀 Tech Stack

This project is built using modern web technologies to ensure a fast, accessible, and stunning user experience:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **UI Components:** Custom glassmorphism components with Radix UI primitives
- **Icons:** Lucide React & React Icons
- **Deployment:** Vercel

## ✨ Features

- **Modern & Premium Design:** Sleek dark mode aesthetics featuring glassmorphism, dynamic gradients, and mesh backgrounds.
- **Smooth Animations:** Integrated with Framer Motion for scroll-triggered reveals, hovering effects, and a custom interactive cursor.
- **Responsive Layout:** Carefully designed to look incredible on desktops, tablets, and mobile devices.
- **Interactive Particle Background:** A custom-built 3D-like particle background in the hero section for a deeply engaging first impression.
- **Dynamic Projects Showcase:** Beautiful project cards featuring AI-generated cover images and detailed tech stacks.
- **SEO Optimized:** Built with semantic HTML and Next.js optimization features.

## 💻 Getting Started

Want to run this project locally? Follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Iamprakharshukla/My-Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd My-Portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
